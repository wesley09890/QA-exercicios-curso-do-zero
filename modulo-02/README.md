# Módulo 02 — Classificação de Bugs e Tipos de Teste

Exercícios práticos desenvolvidos durante o curso QA do Zero, com foco na análise de problemas encontrados durante os testes.

Os exercícios registram:

* Problema encontrado e respectivas evidências
* Classificação do bug
* Tipo de teste aplicado
* Nível de teste
* Justificativa para as classificações realizadas
