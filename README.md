# QA — Exercícios do Curso

Repositório com exercícios práticos desenvolvidos ao longo do **curso QA do Zero**, aplicando conceitos e práticas de Qualidade de Software.

Os trabalhos abrangem testes manuais, documentação de QA, BDD, testes exploratórios, testes de API, SQL, automação e aplicação de conceitos de **metodologias ágeis**, como Scrum e Kanban.

Cada módulo contém os materiais produzidos durante as atividades e seus respectivos relatórios, com contexto, objetivos, procedimentos, resultados e evidências.
